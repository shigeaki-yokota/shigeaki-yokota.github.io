高次元の球面からGaussianが見える

Gaussianベクトルの向きは球面上一様。長さを半径√nにそろえると、できあがるのは半径√nの球面上一様な点そのものだ。次元が大きくなると、その点の少数の座標はGaussianに近づく。では、球面全体もGaussianに近いのだろうか？

ここから始める人へ。ベクトルの長さ、独立な確率変数、平均と分散を使う。最後に出てくる「ピラミッド」は、空間そのものではなく、その空間から距離を広げない写像で作れる距離測度空間を集めたもの。ここでは意味を言葉で説明し、定理の完全な証明は原論文へ案内する。

1 / 出発点

Gaussianの向きを残し、長さだけをそろえる

nを正の整数とし、Gをn+1個の独立な標準正規変数からなるベクトルとする。標準正規変数とは、平均0・分散1で、密度がφ(t)=(2π)−1/2e−t²/2の確率変数。Gの長さをR=|G|と置く。Gaussianの密度は原点からの距離だけで決まるので、向きG/Rは単位球面上で一様になる。したがって

U = (√n / R) G　∈　Sn(√n)

は半径√nの球面上で正確に一様な点だ。ここは近似ではない。Gaussianから球面を作る操作は、向きを変えずに長さだけを調整することになる。

半径についても簡単な計算ができる。標準正規変数ではE[Gi2]=1、Var(Gi2)=2なので、E[R2]=n+1、Var(R2)=2(n+1)。だからE[(R2−n)2]=2n+3。x=R2/nと置くと、x≥0より |√x−1|=|x−1|/(√x+1)≤|x−1|。両辺を二乗して平均を取れば、次の評価を得る。

E[(R/√n − 1)2] ≤ (2n+3)/n2 → 0

つまり半径の相対誤差は小さくなる。次元が増すと、Gaussianの点は半径√nに比べて薄い殻へ集まる。

2 / さわって確かめる

少数の座標と、半径のずれを比べる

下の図はGaussianベクトルを何度も発生させ、長さを√nにそろえたときの第1座標と、元のGaussian半径との差を描く。左では球面座標の分布が標準Gaussianの釣鐘曲線へ近づく。右は半径の絶対的なずれで、左の相対的な尺度とは別物だ。

次元を変えてみる

各標本の乱数列を固定し、次元を変えたときの違いを比べやすくしている。

これは標本数1,800の数値実験で、証明の代わりではない。球面座標は U1=√n G1/R として計算。右の横軸は R−√n で、単位は元の距離のまま。

なぜ少数の座標では誤差そのものが消えるのだろう。球面上の点Uと、それを作ったGは同じ確率空間にある。しかも |U−G|=|√n−R|。各座標の誤差の二乗平均は対称性により等しいので、最初のk座標の誤差は全体のk/(n+1)倍となる。一方、(R−√n)2=(R2−n)2/(R+√n)2≤(R2−n)2/n。以上から

E[ |(U1,…,Uk) − (G1,…,Gk)|2 ] ≤ 3k/n

となる。kを固定すれば右辺は0へ近づく。さらにk/ n→0なら、見ている座標の数も増やしてよい。これは球面のGaussian極限として知られる結果の、直接的な形だ。

3 / ここで分かること

座標で見ると、Gaussianが残る

同じベクトルを使う結びつけ方（カップリング）により、球面上の一様点の最初のk座標と、k次元標準Gaussianを平均二乗誤差で比較できた。特に固定したkでは誤差が消える。密度の形も極限でGaussianとなり、Shioyaの論文ではMaxwell–Boltzmannの分布法則として述べられている。分布の収束とは、有界連続関数で測った平均値が一致していくことを指す。

見えている現象
全体は半径√nの球面にあるのに、有限個の座標だけを測ると、独立な標準Gaussianのように見える。

この結論は「座標をいくつか観測したら何が見えるか」についてのもの。座標方向を選び直しても回転対称性で同じことが言えるが、すべての方向・すべての座標を一度に近づける主張ではない。

4 / 大事な境界

球面の測度とGaussian測度が、同じ場所で近いわけではない

Uは半径√nの球面上にある一方、Gは周囲の空間全体に広がる。前の座標評価の誤差は、k個を見る場合にだけ小さくなる。k=n+1と置くと、右辺は小さくならない。したがって、ここから「同じユークリッド空間上の二つの測度が近づく」とは結論できない。

むしろ、Gaussianの半径が√n付近で持つ幅は、距離の単位では消えない。長さに比べれば薄い殻でも、その厚みをゼロと取り違えてはいけない。次の議論では、この半径方向の違いを保ったまま、1-Lipschitzな観測を比べる。

半径の絶対的な揺れが消えないことも確かめる

Rの密度は、正規化定数cn>0を使ってqn(r)=cnrne−r²/2と書ける。最大値はr=√nで取る。0≤sならlog(1+t)≥t−t²/2（t≥0）を用いて

qn(√n+s) ≥ qn(√n)e−s²

となる。左辺を半直線上で積分しても全確率1を超えないため、qn(√n)≤2/√π。よって

P(|R−√n|≤1/4) ≤ 1/√π

したがって、少なくとも1−1/√π（約0.43）の確率で半径は√nから1/4より大きく離れている。割合の揺れは消えても、絶対的な距離の揺れは消えない。

区別しよう。有限座標の分布収束、同じ周囲空間での測度の近さ、ピラミッドの収束は、別々の主張。それぞれに別の議論が必要。

5 / 核心となる写像

外側だけを縮めて、球面へ送る

Gaussianをそのまま球面へ正規化する写像は、原点に近い二点を大きく引き離すことがあり、距離を保つ観測に向かない。代わりに、半径aより内側はそのまま、外側だけを球面まで縮める写像を使う。

Ta(x) = x　(|x|≤a),　　Ta(x)=a x/|x|　(|x|>a)

ここでいう1-Lipschitzとは、どの二点x,yについても、写像後の距離が元の距離以下になること。すなわち |Ta(x)−Ta(y)|≤|x−y| という性質だ。点を極座標でru, svと書くと、距離の二乗は (r−s)2+rs|u−v|2。写像後は半径がmin(r,a), min(s,a)となるので、半径差も角度項も増えない。

ここでa=(1−δ)√nとし、0<δ<1を固定する。Gaussianベクトルの半径がa以上なら、Ta(G)は半径(1−δ)√nの球面上にある。半径の二乗の平均と分散から、内側に入ってしまう例外確率は

P(R < (1−δ)√n) ≤ 4/(nδ2)

で抑えられる。δを固定すれば例外確率は0へ向かう。その後でδを0へ近づけると、半径の比は√nに対して1へ近づく。球面の絶対的な半径差を固定δのまま小さくするのではなく、この比の極限を使ってGaussian側の観測から球面側へ進む。

直感の要点
半径を正確に一致させる必要はない。距離を増やさず、少し小さい球面まで縮めると、ほとんどすべてのGaussian点を受け止められる。

6 / どんな意味で近づくのか

有限次元だけでなく、観測できる空間全体を比べる

距離測度空間（mm空間）は、距離と確率測度を組にした空間だ。mm空間Xの関連ピラミッドPXは、Xから距離を広げず、確率測度も保つ写像で得られるmm空間に、box距離で極限を取って加えた集まり。この集まりは、Xが1-Lipschitzな観測を通して何を実現できるかを記録する。

box距離では、二つのmm空間を一様分布のパラメータ空間[0,1]から表す。ただし、各パラメータ写像は一様分布をそれぞれの空間の確率測度へ移す。測度が1−ε以上ある同じ部分集合を取り、その中のすべてのパラメータの組で二点間距離の差がε以下になるようにできるかを測る。mm空間XとピラミッドQの距離を □(X,Q)=infY∈Q□(X,Y) と書く。ピラミッド列QnがQへ弱収束するとは、(i) 各X∈Qで□(X,Qn)→0、(ii) 各X∉Qでliminf□(X,Qn)>0となること。有限個の有界な観測については、観測の個数と値域を固定し、それらが作る分布の集合どうしを比べる。あらかじめ選んだ一つ一つの観測が収束するだけでは足りない。Shioyaの証明では、この一様な比較とピラミッド位相の定義が結びつく。結果は

PSn(√n) → PΓ∞

となる。右辺の「無限次元Gaussian」は通常の有限次元Gaussian空間ではなく、全ての有限次元標準Gaussian空間に対応する関連ピラミッドを集め、その和集合をbox距離で閉じたもの。Shioyaの定理では周囲のユークリッド距離を球面に制限した場合にこの収束を示す。球面に沿ったRiemann距離についても、Kazukawaが同じGaussianピラミッドへの収束を証明している。

このページの計算から定理へ進む道

R≥aのとき、Ta(G)=aG/Rであり、半径と向きは独立なので、この部分は球面上一様分布に従う。例外R<aの確率をpとすると、切り詰め後の分布は「球面上一様分布を重み1−p、内側に残る分布を重みp」とする混合。だからProkhorov距離での誤差はp以下となり、前節の評価で0へ向かう。Prokhorov距離は、確率質量のε分まで例外として許し、残りをε以内だけ動かして一致させる測度間の距離。正式な定義はShioyaのDefinition 2.10にある。

さらに、観測の値域を有限精度の格子で近似すると、固定した観測数・範囲で任意の有限次元からの分布を有限個の代表で近似できる。これが各有限次元での一様な比較を作る。Shioyaの証明はまず縮小率θを固定し、切り詰め後の分布比較をピラミッド比較へ移す。次にθを1へ近づけ、ピラミッドのスケール変化が弱収束と両立する補題を使って極限を特定する。半径の絶対差を0へ送る主張ではなく、スケールの比とピラミッドの連続性を組み合わせる議論だ。ここで説明した式だけが論文の証明全体だという意味ではない。

距離の注意。球面の弦距離と球面に沿う距離は異なる。ピラミッド極限を述べるとき、どちらの距離を使うかを明記する必要がある。このページでは主に弦距離の定理を説明した。
