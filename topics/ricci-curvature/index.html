Ricci曲率は何を数えているのか

「断面曲率の和」と言われても気持ちがわからない。曲率を動かし、Jacobi場を解き、体積密度と第二変分の計算を確かめる。ときどき変な脇道にも入る。

小さな数値実験はJacobi方程式を用いた理想模型のもの。曲率の一般論や実在する空間を二つの数字だけで再現するものではない。

1 / 直観

まず、曲率を「曲がり具合」だと思うのをやめてみる。

曲率は、図形がどう曲がって見えるかだけの話ではない。近くを出発した測地線同士が、これからどう離れていくかという未来予測の数字として読める。

地図の上で一点を選び、そこから無数の最短経路を出発させる。Euclid空間なら測地線の束は素直に広がる。曲率があると、その束は期待より狭くなったり、広くなったりする。

では、進む方向を一本 v に固定して、v に垂直な微小断面の広がりを見るとどうなるのか。ここで、Ricci曲率が登場する。

「一本の道に沿って、
　周囲の空間がどれほど集まるか。」

これは比喩だけれど、あとでJacobi場の行列式を計算すると、実際にかなり正確な説明になる。

2 / 断面曲率

正のRicci曲率なのに、負の断面曲率がいてもいい。

3次元で単位ベクトル v を決めよう。直交する二つの方向 e₁, e₂ について、曲率演算子の固有方向を選べば、Ricci曲率は二つの断面曲率の和になる。

Ric(v,v) = K(v,e₁) + K(v,e₂)

たった二つの数を足しただけなのに、幾何的な情報が一気に潰れる。ここを触ってみよう。

数字を動かすと、Ricci曲率と下の測地線模型が同時に変わる。

注意：このミキサーは、一点・一方向での曲率演算子の二つの固有値を扱う理想化した設定。任意の空間全体の曲率を、この二つの数字だけから復元できるわけではない。

そもそも、Ric(v,v)/(n−1) が、進行方向 v を含む断面曲率の平均にあたる。和が正だからといって、一つひとつが正とは限らない。

本日の危険な直感：「Ricci曲率が正なら、あらゆる向きに曲がっている」は嘘。正しいのは、特定の方向へ進むとき、その方向に垂直な曲率の和が正ということ。
3 / 測地線と体積

測地線を育てると、体積密度の変化にRicciが現れる。

曲率は測地線を曲げる。測地線が集まれば、同じ角度の束で運ばれる体積は小さくなる。では、その「集まり方」の最初の差は何が決める？

ここでは曲率演算子が、測地線に沿って一定で対角化できる模型を使う。先ほどの二つの曲率 k₁, k₂ を引き継ぎ、直交するJacobi場の長さを j₁(r), j₂(r) とする。

jᵢ″(r) + kᵢ jᵢ(r) = 0,
jᵢ(0) = 0,  jᵢ′(0) = 1

その横断面の面積密度は J(r)=j₁(r)j₂(r)。Euclid空間なら J(r)=r² なので、比 J(r)/r² を表示する。

重要： 実線は「曲率演算子が測地線に沿って一定」という理想模型での厳密な計算。赤い線は原点付近の二次近似。一般のRiemann多様体で、Ricci曲率の一点の値から有限距離の密度を厳密に求められるという意味ではない。

一体、何がわかったのか。

グラフの原点付近では、曲率の配分を変えても同じRicci曲率なら同じ二次の振る舞いをする。つまりRicci曲率は、体積密度の最初の変形を記録している。

J(r) / r² = 1 − (Ric(v,v) / 6) r² + O(r³)

これは一般の滑らかな3次元Riemann多様体でも、十分小さな r について成立する（測地線極座標のJacobian）。ただし、ここで使用している一定係数の模型では余りを O(r⁴) に強められる。

同じRicciでも、その後の全過程は同じではない。 曲率の情報を和に圧縮したときに、何が残り、何が捨てられたかを体感できるはず。

4 / 計算

なぜここに 1/6 が出てくる？

数学の解説は、「なんとなく集まるから」で止めない。この係数を証明で取り出してしまおう。

補題｜一定曲率演算子の模型でのJacobianの展開

上の模型で、各 jᵢ は線形常微分方程式

jᵢ″ + kᵢjᵢ=0,  jᵢ(0)=0,  jᵢ′(0)=1

を満たす。従って jᵢ″(0)=0、微分して jᵢ‴(0)=−kᵢ を得る。Taylor展開から

jᵢ(r) = r − (kᵢ/6)r³ + O(r⁵).

ゆえに

j₁(r)j₂(r) = r² − (k₁+k₂)r⁴/6 + O(r⁶).

最後に k₁+k₂=Ric(v,v) を代入して

J(r)/r² = 1 − Ric(v,v)r²/6 + O(r⁴).
□

一般の場合はJacobi場をベクトル値で考え、曲率演算子の行列のtraceを取る。そのtraceがRicci曲率になる。「曲率の足し算」と「体積の変化」がここで合流する。

裏路地メモ

もし最初にRicci曲率の定義だけを聞いたら、traceを取る必然性はよくわからない。でも「近くの測地線たちが作る微小平行六面体の体積を知りたい」と考えると、行列式の微分でtraceが現れるのはむしろ自然。Ricciは、そのとき現れる名前だったのかもしれない。

6 / 第二変分

正のRicci曲率は、長すぎる最短経路を許さない。

Bonnet–Myersの定理の不思議さは、各点の微分的な条件から、空間全体の直径が制限されるところにある。

Ric ≥ (n−1)κg,  κ>0
⇒ diam M ≤ π/√κ

証明は測地線の第二変分から始まる。長さ L の単位速度最短測地線 γ に沿って、平行正規直交枠 E₁,…,Eₙ₋₁ を選ぶ。そして

Vᵢ(t) = sin(πt/L) Eᵢ(t)

で変分する。このとき最短性から Σ I(Vᵢ,Vᵢ) ≥ 0。しかしRicci下限から、同じ和は

Σ I(Vᵢ,Vᵢ) ≤ ((n−1)L/2)(π²/L² − κ)

とも評価できる。長さが π/√κ を超えると右辺は負！ つまり、最短だったはずの測地線が最短ではあり得ないという矛盾に達する。

MYERS TEST BENCHκ = 1, n = 3
+0.00
Σ I の上界 = π²/L − L
π ≈ 3.1416 を超えると上界が負になり、最短性と両立できない。
証明｜Bonnet–Myers

M を完備連結な n ≥ 2 次元Riemann多様体、Ric ≥ (n−1)κg、κ > 0 とする。Hopf–Rinowにより任意の二点を最短測地線で結べる。長さ L のそれを単位速度でパラメータ化し、上記の変分場を取る。index formの非負性とRicci下限から

0 ≤ ΣI(Vᵢ,Vᵢ) ≤ (n−1)L/2 · (π²/L² − κ).

従って L ≤ π/√κ。二点は任意なので直径評価が従う。有界閉集合がコンパクトとなるHopf–Rinowの帰結より M はコンパクトである。

□

実験台が表示するのはindex formの「上界」。一般の多様体におけるindex formの正確な値そのものではない。この区別を曖昧にしないのも、遊べる教材の大事なところ。

7 / CD条件

CD条件は、「Ricci曲率」を微分なしで語るための言語。

Ricciの意味を体積変化として見ると、次の疑問が自然に生まれる。微分ができない距離空間に、曲率の同じ気持ちを持ち込めないだろうか。

その一つの答えが、測度距離空間上での最適輸送とエントロピーの凸性。滑らかな多様体では、適切なWasserstein測地線 (μₜ) に沿って、エントロピーの二階変分に

∫ (|Hess φₜ|² + Ric(∇φₜ,∇φₜ)) dμₜ

が現れる。だからRicci曲率の下限は、エントロピーの凸性に結びつく。太田慎一『Ricci curvature, entropy and optimal transport』 は、この橋渡しを学ぶためのよい出発点。

STEP 01Jacobi場測地線の束がどれほど膨らむか。
STEP 02最適輸送束を、確率測度の動きとして見る。
STEP 03CD(K,N)凸性・歪み係数を距離と測度だけで定式化する。
見落としがちな違い： 「CD(K,∞)でK>0」と「有限のNでCD(K,N)」を混同してはいけない。標準Gaussian測度付きEuclid空間はCD(1,∞)を満たすが、台は非コンパクト。有限次元の仮定が合成的Myersの結論には決定的。

この章はまだ「橋の見取り図」。有限 N の歪み係数とRényiエントロピー、滑らかな同値定理の完全な証明、FinslerとRCDの違いは、それぞれ長い独立ページにしたい。

8 / 余談

胡乱な数学・曲率の怪文書棚

数学のサイトなら、脚注を踏んだ途端に別の世界へ転げ落ちてもいい。まずは、答えを開くまで少し考えたい小話を並べてみた。

QUESTION 001Ricci曲率がゼロなら、空間は平坦？

次元による！ 3次元ではRicciテンソルがRiemann曲率テンソルを決めるため、Ric=0なら平坦。一方、4次元以上にはRicci-flatだが非平坦なRiemann多様体がある。K3曲面のCalabi–Yau計量は有名な例。

QUESTION 002Ricciが各点で正なら、空間はコンパクト？

一様な正の下限が必要。 ただ正だというだけでは足りない。非コンパクトな回転放物面は完備でGauss曲率が正。2次元ではRic=Kgだから、Ricが正で非コンパクトな例になる。

QUESTION 003正の曲率があれば、Gaussianは閉じ込められる？

標準Gaussian測度を備えたEuclid空間は Ric∞=I を持ち、CD(1,∞)の典型例。しかし直径は無限。有限次元条件との違いが顔を出す。

QUESTION 004曲率って、どうしてtraceを取るの？

測地線変分の行列式が体積密度を与えるから。行列式の一階変分にtraceが現れる。Ricciは「いっぱいある断面曲率を雑に足した量」ではなく、体積という幾何量が選び取ったtraceとして眺められる。

QUESTION 005CD条件を満たせばRiemann的？

そうとは限らない。Finsler多様体も適切なCD条件を満たす。RCDでは無限小Hilbert性を追加して、非Riemann的なFinsler挙動を排除する。

QUESTION 006同じRicなら、測地線の集まり方も同じ？

原点付近の二次のずれは同じ。しかし、同じRicでも個々の断面曲率やその変化は異なり得る。上の実験室の二つの模型は、その違いを可視化している。
